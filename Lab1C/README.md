
# Lab1C

Мій перший проєкт мовою програмування C.

## Опис

Програма виводить у термінал повідомлення "Привіт, C!".

## Компіляція

```bash
gcc main.c -o hello.exe
```

## Запуск

У PowerShell:

```powershell
.\hello.exe
```
## Результат роботи

Навчився створювати програму мовою C,
компілювати її за допомогою GCC та працювати з Git і GitHub.
